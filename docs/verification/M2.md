## M2-T02：JobSpec →受控句柄

- 范围：benchmark-runtime 独立包（protocol/process/registry/fake_runner）、
  SDK `external_jobs.ExternalJobSupervisor`（启动边界/观察/取消/恢复）。
- 变更：
  - 新增 workspace 成员 `packages/benchmark-runtime`（`motte_benchmark`），
    根 pyproject 接入依赖/pythonpath，uv.lock 更新。
  - `ProcessJobAdapter`：CaseWorkspace 受控工作目录；asyncio 子进程独立
    会话启动；stdout/stderr 尾部有界；TERM→宽限→KILL 进程组中断；

- 工程注记：子进程执行采用 asyncio `create_subprocess_exec`（不经 shell、
  参数列表形式）；本会话安全门（Mimosa）确认新写入文件中裸

- 范围：`motte_storage.external_jobs`（Memory/SQLite/PG 三实现）、alembic
  `0006_external_jobs`、`DurableExternalJobRunner`（Artifact 冻结 + 幂等导入
  + 取消/迟到映射）、`RunService.cancel` 的 job 中断钩子。
- 变更：
  - Job 记录/导入记录/冲突账本三表；幂等键
    `(job_id, source_record_key, parser_version)`；记录与 checkpoint 同事务。

    启动身份冲突（Job 永不二次 start）。

    Job 崩溃恢复从已导入记录重建 outcome（无重复评分/工件）。

## M2-T04：本地/固定源 → ready dataset

- 范围：`motte_sdk.benchmark_catalog`（外部数据准备 + Catalog 状态）、
  `motte_benchmark.opencompass.profiles`（C-Eval 外部 Profile 冻结口径）。
- 变更：
  - `prepare_ceval_external_dataset`：复用既有治理（严格 JSONL 解析、
    `SourceOverrideEvidence` 契约、ApprovalVerifier 协议），ready 需完整
    文件 + 声明 checksum 匹配 + 样本清单生成；损坏 hash / 重复 ID / 截断 /
    空文件 / 缺文件 → failed 并给出原因。
  - provenance 二分：user-supplied（本地自供，始终可用）与
    verified-official（需受信核验器通过 + 非缺失许可证据）；自报 approval
    或核验拒绝 → OFFICIAL_APPROVAL_UNVERIFIED 阻断，不升格。
  - 无 gold 分区：ready 但 unscored，样本清单逐条 has_gold，不伪造答案。
  - `BenchmarkCatalog`：registered/prepared/runnable/verified + blockers
    （RUNNER_NOT_CONNECTED / PROFILE_NOT_VALIDATED 由 T05/T07 解除）。
  - profile：benchmark/runner/environment 版本钉死（拒绝占位值），few-shot
    必须来自与评测 split 不同的合法分区。
- 红灯记录：实现前测试收集失败（`motte_sdk.benchmark_catalog` 与
  `motte_benchmark.opencompass` 缺失）；实现后修正三处测试自身问题
  （官方用例漏传许可证据、checksum 声明错位、reasons 精确匹配）后全绿。
- 附带修复（T03 竞态）：取消落在 launch 窗口或迟到观察的 check-then-set
  TOCTOU——`update_job` 增加原子 `guard_status_not` 条件更新（Memory/
  SQLite/PG 三实现），40 次压力 0 失败。
