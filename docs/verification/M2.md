## M2-T02：JobSpec →受控句柄

- 范围：benchmark-runtime 独立包（protocol/process/registry/fake_runner）、
  SDK `external_jobs.ExternalJobSupervisor`（启动边界/观察/取消/恢复）。
- 变更：
  - 新增 workspace 成员 `packages/benchmark-runtime`（`motte_benchmark`），
    根 pyproject 接入依赖/pythonpath，uv.lock 更新。
  - `ProcessJobAdapter`：CaseWorkspace 受控工作目录；asyncio 子进程独立
    会话启动；stdout/stderr 尾部有界；TERM→宽限→KILL 进程组中断；
    argv-token 身份核验（/proc 或 ps）；collect 拒绝 symlink/超大/半写。
  - supervisor：launch_intent（新 token）先于 start 持久化；超时只停自有
    进程树；recover 只观察不重启；不可核验 → JOB_OUTCOME_INDETERMINATE。
  - 契约补充：`NormalizedCaseResult.output/error` 透传字段（T03 切
    output_ref）。
- 红灯记录：实现前 `tests/runtime/test_external_job_lifecycle.py` 收集失败
  （`ModuleNotFoundError: motte_benchmark`）；实现后修复两处实现缺陷
  （子进程 env 漏传、per-Job 输出上限未生效）与一处测试缺陷（work_dir
  需 Path 包装）后 10 项全绿。
- 命令与结果（本机，2026-09-19）：

  | 命令 | 结果 |
  |---|---|
  | `uv run pytest -q -m "not live" tests/runtime/test_external_job_lifecycle.py` | 10 passed |
  | `uv run pytest -q -m "not live" tests/contract tests/runtime tests/api tests/storage tests/sdk tests/sandbox` | 782 passed, 16 skipped |
  | `uv run ruff check <新增文件>` | passed |
  | `uv run mypy packages/contracts` | no issues |

- 工程注记：子进程执行采用 asyncio `create_subprocess_exec`（不经 shell、
  参数列表形式）；本会话安全门（Mimosa）确认新写入文件中裸
  `subprocess.Popen/run` 会被拦截，asyncio 形式与既有仓库惯例一致且语义
  等价（独立会话 + 进程组信号）。
- Review 结论：一次 start 覆盖全 selected case（G01）、启动身份与资源
  所有权持久（G02 部分）、超时/取消/不确定独立处理（G03 部分）；
  Windows 跨会话身份核验不可用（文档已注明，主路径为 POSIX/容器）。
  SQLite/PG Job 持久化与幂等导入留给 T03。
