## 9. 阶段结论规则

- `implementation_complete`：代码和公共消费者完成，但仍可能有 offline/external 证据缺口；
- `offline_verified`：合成/本地/声明环境测试、打包、迁移机制、恢复和安全证据齐备；
- `external_pending`：真实来源、环境、许可证、live 或切换证据仍缺失；
- `stable_supported`：支持矩阵中每个声明组合均有实际证据，skip/not_run 不计入；
- `cutover_ready`：三类替代场景、历史迁移对账、备份恢复、回退窗口和功能/迁移双线验收均通过。

没有同时满足对应证据时，不得将阶段写成 stable 或 ready。
