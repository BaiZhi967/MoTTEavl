## 兼容边界

- 新数据持久化 `preparation.default_split`。旧 payload 仍可读；缺 preparation 与空对象视为同一未知语义，旧记录无变化读写保持幂等。旧未知准备参数与新明确参数不能证明等价，使用新 revision 重新准备。
- OpenCompass Runner 的目标 gold 不进入推理数据；推理输出由平台冻结 case_expectations 评分。没有原生聚合时 native 指标为空，不能制造官方准确率；已有含原生结果的历史 Parser 输入继续保留 native/diagnostic 两份值。
- Python 3.12 的上游依赖安装受 pandas 1.5.3 兼容限制；Runner 使用独立 Python 3.10，API workspace 依赖不增加 OpenCompass。
- 本轮不运行付费模型、官方数据 full Profile 或真实模型 smoke；这些仍按 M2 原验收范围单独登记，不能因本地确定性端点通过而声称已验收。
