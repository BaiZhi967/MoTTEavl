## 已知基线现象（已在第二轮 review 修复根因）

`tests/test_dev.py::test_cleanup_owned_descendants[False]` 在完整套件中偶发
`os.killpg(pid, 0) PermissionError`（进程组 PID 回收竞态），单文件运行恒过。
规划期（440d532 前）已两次出现；第一轮实现期复现 3 次（未掩盖、单独记录）。
第二轮 review 期间连续阻塞 make check，完成根因修复：0-signal 探测自己的
进程组对同 uid 调用者不会 EPERM，EPERM 恰恰证明 pgid 已被无关组回收（本组
已消散），`Child.stop()` 据此停止轮询并跳过对回收组的 SIGKILL，而非崩溃。
修复后完整套件连续 3 次通过；断言未削弱、未跳过。
