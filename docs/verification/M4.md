## M4-T01 — Runtime 契约、不可变资源与 backend 条件校验

**状态：完成（contract + storage 级离线证据）。**

### 实现路径

- 新增 `packages/contracts/motte_contracts/runtime.py`：
  `RuntimeDefinition`（kind/transport/upstream_version/adapter/parser 版本、
  config_schema 字段 allowlist、supported_modes/interactive 一致性、
  model_control 三值、`RuntimeToolControl`、evidence_capabilities 白名单）、
  `RuntimeVersion`（仅 published、立即不可变）、`RuntimeProfile` /
  `RuntimeProfileVersion`（workspace 来源约束、credential_refs 仅凭据档案名，
  常见密钥前缀拒绝）、`validate_runtime_settings`（按 config_schema 的字段
  allowlist 与类型校验，未知字段拒绝）、`runtime_readiness`（installed →
  protocol_ready → execution_ready 分层及原因）。
- `packages/storage/motte_storage/resource_store.py`：新增 `runtimes`
  （runtime_versions）与 `runtime_profiles`（runtime_profiles）两个版本化
  资源（VERSIONED_TABLES：同内容幂等、异内容冲突、不可删除）；InMemory /
  SQLite 同语义；PG 由迁移建表。
- `migrations/versions/0009_runtime_resources.py`：PG 建表（head 0008 → 0009）。
- 新增 `packages/sdk-python/motte_sdk/runtime_backends.py`：
  `validate_runtime_manifest`（runtime 引用与 backend 身份一致、快照必须为
  已发布版本、model_control 三分支：platform-controlled 必须有解析后的
  provider 快照与发布模型引用；runner-configured 必须有通过 allowlist 的
  原生模型设置；externally-managed 必须声明凭据引用）、
  `register_runtime_backend` / `install_runtime_backends`（注册
  pi-agent/claude-cli/codex-cli/codex-app-server 四个 backend；
  build 在 T04/T06/T07/T10 接线前显式 `RUNTIME_EXECUTION_NOT_IMPLEMENTED`，
  不假成功）。
- `packages/sdk-python/motte_sdk/resolve.py`：`resolve_manifest` 解析
  `manifest.runtime` → 已发布 RuntimeVersion 快照（content_hash、
  model_control、tool_enforcement、config_schema）写入
  `runtime_snapshot` / `resource_snapshots.runtime_version`；
  `runtime_profile` 支持内联或 name@version 资源引用展开并回填 config_hash；
  非 platform-controlled 且未声明 provider/model 时不伪造平台 provider
  （`_connection_for` 返回 None）；managed 套件的 provider 强制改为按
  model_control 条件化。
- `packages/sdk-python/motte_sdk/execution_backends.py`：`resolve_execution`
  支持由 `manifest.runtime` 派生 backend 身份；runtime 与 legacy runtime
  字段（agent/skills/harness/pi）互斥；`_reject_unconnected_runtime_fields`
  扩展 runtime 字段（direct/replay 不接受 runtime）。
- `packages/contracts/motte_contracts/scenario.py`：`ScenarioSpec.model`
  改为可空（provider 驱动路径仍在 prepare_run/resolve 强制模型解析，
  不放宽旧校验）；`contracts/run.py` `ResolvedManifest` 增加
  runtime / runtime_profile / runtime_snapshot 字段。
