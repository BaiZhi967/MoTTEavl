## M4-T03 — 真实 Pi bridge

**状态：完成（protocol + 真实 SDK 集成级离线证据）。**

### 实现路径

- `bridges/pi/bridge.mjs` v2.0.0（协议 v2）：probe / init / run / interrupt
  控制消息严格串行分发（promise 链，init 的 async 完成前不处理后续消息）；
  stdout 仅协议（每事件携带 run/case/session/operation 身份与单调 seq）；
  stderr 有界（64KB）且脱敏（工具错误只留首行 120 字符，避免参数 JSON 回显）；
  SDK 加载失败 → probe execution_ready=false + init/run `PI_BACKEND_UNAVAILABLE`，
  绝无 echo/builtin fallback；裸 `prompt` 消息 → `UNSUPPORTED_MESSAGE`。
- `bridges/pi/session.mjs`：真实上游 `Agent`（@mariozechner/pi-agent-core@0.73.1）

  max_tool_calls 超限（确定性 block，而非事后 abort）；max_steps 步数预算；
  中断（interruptRequested 标记 → agent.abort → interrupted 先于 finished）；
  usage 诚实保持未上报（scripted model 无真实计量，不填 0）。

  未知事件/多余字段全部 fail closed、结构化错误保留 code 且不透传 bridge
  文本、interrupt 与进程树清理。
- 依赖：`@mariozechner/pi-ai@0.73.1` 提升为 bridges/pi 直接依赖（pnpm 不

## M4-T04 — Pi 平台纵向链路

**状态：完成（integration 级离线证据：真实 bridge 驱动 RunService 全链路）。**

### 实现路径

- `packages/sdk-python/motte_sdk/pi_runtime.py`（新增）：
  `PiRuntimeCaseExecutor` —— 每 CaseAttempt 独立 session/workspace：
  session_id/operation_id 每次全新（无跨 Case 复用；续跑走 retry 子 Run）；
  事件经 `service.emit_run_event` 持久化（`pi_*` 类型 + case/session 归属）；
  模型调用记 InvocationRecord（metering_source=scripted-model，usage 未上
  报如实记录）；产物经 ArtifactStore 冻结；Observation 满足
  FrozenObservation 契约（termination 词表映射、usage reported=false）；
  取消 watcher 线程轮询 run cancellation → session.interrupt()；异常路径
  保留原始异常与 evidence，cleanup 失败如实上报残留。
- `runtime_backends.py`：`_build_pi` 接入 pi-agent@1（ExecutionHandle：
  invoke + attach + capabilities{runtime,events,artifacts}）；
  `CANONICAL_RUNTIME_VERSIONS`（四个 backend 的规范定义，与
  runtime-compatibility.json 同构）+ `publish_canonical_runtime_versions`
  （幂等发布进资源仓库）。
- `resolve.py` / `agent_tasks.py` / `execution_backends.py` 的 runtime 条件化：
  agent-tasks 场景显式 runtime 时不强制平台模型/provider、不写 agent 字段；
  provider 注入（max_retries）只在 provider 存在时进行；`runtime_accept_unenforced_tools`
  进入 ResolvedManifest。
- Python 侧工作区：`_PiCaseWorkspace`（fixture 物化路径校验、lstat symlink
  检查、快照 hash、归属校验清理）。执行期边界在 bridge 侧（tools.mjs）；
  POSIX fd 链沙箱（motte_sandbox）在 Windows 上不可用（os.open 目录语义），
  该限制为本机既有环境边界（builtin-agent 的同类用例在主干同样失败），
