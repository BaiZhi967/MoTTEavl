  `manifest.runtime` → 已发布 RuntimeVersion 快照（content_hash、

### 验收对照（M4-A01）

- 未安装：`installed=false`，原因 "binary is not installed (no auto-install)"。
- 版本不兼容：`installed=true` + `protocol_ready=false`，原因含漂移版本与
  pinned 版本；fail closed。
- 缺认证：externally-managed 的 CLI 在创建层要求 credential_refs（T01 的
  `RUNTIME_AUTH_REQUIRED`）；auth 实际可用性属 live 验证，不在静态 probe 内
  读操作者凭据。

- claude/codex 二进制未安装在本机：本阶段协议夹具为合成（按官方文档格式），
  真实 --version/捕获需安装环境或 live 授权后补充；不据此宣称 CLI 执行支持。
- app-server 协议子集（thread/turn + codex/event）按文档构造，真实握手验证
  在 T10 与 live 单列。
