# M3 Harbor / Terminal-Bench Implementation Plan

> **For agentic workers:** 使用 superpowers:subagent-driven-development 或 superpowers:executing-plans 逐任务实施；步骤以复选框记录。本文是开发交接，不是 M3 已实现证明。

**Goal:** 完整实现 M3 的 18 个目标、10 个工作包、15 个强制验收场景，交付固定 Terminal-Bench 2.x × Agent Profile × 环境的 Task/Trial/Verifier 用户链路。

**Architecture:** 复用 Dispatcher → DurableExternalJobRunner → Adapter；Harbor 管理任务环境，平台持有启动、恢复、导入和评分主权。一 Task 对应逻辑 CaseRun，事前冻结的 Trial 单独存储；原始证据先冻结再解析与评分。

**Tech Stack:** 当前 uv Python workspace、Pydantic/FastAPI、SQLite/PostgreSQL/InMemory、React/Vite、独立固定 Harbor Runner、Docker。

**Spec:** [M3 完整需求](../../roadmap/M3-harbor-and-terminal-bench.md)、[原逐包计划及完整 G/A 覆盖矩阵](2026-09-19-m1-m7/M3.md)、[总约束](../../roadmap/README.md)。本文补充当前接口差异、决策顺序和执行细节，不缩减原需求。当前核对基线为 `7774f42` 加本分支 M2-R4 修复；修复验证见 [记录](../../verification/M2-R4-fixes-2026-09-20.md)。

## Global Constraints

- “Run、Case、Trial、传输重试、操作员 retry 和评分 pass 的身份分开。”
- “已发布资源与终态评分不可覆盖。” MetricResult 仍进入既有 ScoreSet；GET/report/compare/gate 不执行任务。
- “默认测试不使用真实模型或个人订阅。” 离线、真实本地 Docker、真实模型三层分开；真实模型调用另行授权。
- Task 容器不得获得宿主凭据、平台数据库、Docker socket。可信 Runner 的 Docker 管理权限与任务权限分开。
- 先固定真实包版本、来源 commit、任务 hash、Agent 版本及 image digest，再执行；不能使用 latest 或仅写 Terminal-Bench 2.x。
- 新 migration 接在实施时实际 head 后；保留原有无 Trial Run 的读写。不得另建调度系统、复制 Provider 或另写一套 Gate。
- UI 开工前读根 AGENTS.md、apps/web/DESIGN.md 和其指定项目 skill；使用 tokens、STATUS_META、Radix、Phosphor。
- 不实现 M4–M7；M6 只消费现有 Lite 比较/覆盖接口。M3 不自行补齐完整 pass@k 统计。

## Review Focus

- 相同 basename、路径别名或任务内容变更导致错误合并：T01 验证身份及受控读取。
- 多 Trial 被 Case 级唯一键或首次完成吞掉：T02/T06 验证六个计划单元完整、幂等和重启。
- reward=0/缺失/Verifier timeout 混为一类、分母缩小：T04/T08 验证 1/0/error 样例。
- wrapper 死亡但容器仍在执行：T07 验证只观察、不重启、不清理无关资源。
- 已冻结证据在恢复/重复导入中丢引用，或 UI 显示其他 Trial 证据：T06/T09 验证 hash、来源与迟到响应隔离。

## 3. 拟新增接口与不变量

以下代码块为接口声明和验收断言示意，需在测试中构造对应 fixture，不是可直接执行的完整测试文件。以下是拟实施公共交接签名，不是当前已经存在的 API。字段经 T02 契约 review 后统一更新消费者。

```python
# packages/contracts/motte_contracts/trial.py
class TaskIdentity(Contract):
    source_id: str
    dataset_revision: str
    normalized_relative_path: str
    task_content_hash: str
    upstream_task_id: str | None = None

class TrialPlan(Contract):
    trial_id: str
    run_id: str
    task_key: str
    repeat_index: int  # >= 0，计划内唯一，不因传输重试改变
    seed: int | None
    agent_config_hash: str
    environment_hash: str

class VerifierObservation(Contract):
    status: str  # scored / missing_verifier_evidence / verifier_protocol_error / verifier_error
    rewards: dict[str, float]  # 原始维度；finite，bool 不接受为 number
    evidence_refs: list[EvidenceRef]
    error: dict[str, object] | None = None

class TrialResult(Contract):
    trial_id: str
    source_trial_id: str | None
    disposition: str  # succeeded/failed/not_attempted/cancelled/indeterminate
    termination: dict[str, object]
    verifier_observation: VerifierObservation
    artifact_refs: list[EvidenceRef]
    usage: dict[str, object]  # unknown 不填 0，含来源/coverage
```

契约中使用 Literal/Enum、严格类型和范围验证；上述注释不是允许任意 status 字符串的实现。`TrialResult` 不嵌入秘密或巨大文本。Task 的展示名不参与唯一键；Task hash 为排序后的受控相对路径与文件字节 hash 的规范 JSON 摘要；权限/网络/镜像等执行语义另进 environment fingerprint。

```python
# harbor/tasks.py：只读，不运行任务包内容
def prepare_task_manifest(root: Path, *, source_id: str, revision: str) -> dict[str, object]: ...
# harbor/config.py：仅 allowlist，输出非秘密快照
def build_harbor_config(manifest: dict[str, object], plans: list[TrialPlan],
                        profile: dict[str, object]) -> dict[str, object]: ...
# harbor/parser.py：只消费已冻结文件，不能再次访问运行目录
def parse_harbor_files(files: dict[str, bytes], plans: list[TrialPlan],
                      *, parser_version: str) -> list[TrialResult]: ...
# storage/trials.py：相同 plan/result 幂等，异内容冲突；终态不可覆写
class TrialRepository(Protocol):
    def create_plans(self, plans: list[dict[str, object]]) -> list[dict[str, object]]: ...
    def list_for_run(self, run_id: str) -> list[dict[str, object]]: ...
    def put_result(self, trial_id: str, result: dict[str, object],
                   *, source_hash: str, parser_version: str) -> dict[str, object]: ...
```

Trial ID 由冻结计划身份派生；source_trial_id 保存上游身份，两者不可混用。导入幂等键包含 job、trial、parser version；同键异 hash 保留冲突、阻止正式评分。Attempt 保留单独 ID/attempt_no，不增加 planned repeat。Task CaseRun 只在聚合阶段形成一次；已有未完成 Task 不阻碍另一个 Trial 独立落库。
