- 按共同子集过滤难例导致 Gate 放行，T02/T03 使用原 selected 集。

## 1. 进入条件与分批安排

Lite 消费 M1 固定报告即可；Full 按各任务依赖消费 M3/M4/M5。

1. Lite T01 → T02 → T03 随 M2 交付，禁止依赖 M2-T09。
2. T04 → T05：矩阵预览、幂等分配；可在 M3/M5 实施时提前安排。
3. T06 → T07 → T08 → T09 → T10 → T11：统计资格、baseline、完整规则、UI/CI 与跨类型 review。

工程量估算 28–46 人日，包含实现、focused 回归和工作包 review，不包含等待许可证据、预算批准、外部环境与人工标注。它是初步排期范围，不是交付承诺；完成前两包后按实际吞吐重新估计。每个工作包一般拆 1–3 个可独立测试的提交，固定“一项主功能 + 一项验证”的在制品限制。

## 2. 工作包实施卡

接口字段、错误与不变量以本阶段 Spec 第 3 节及后续契约章节为输入；下方“消费 → 产出”明确交接边界。远期 Python 私有函数签名不预先锁死；实际开工时先核对已合入公共契约并补可执行单测，再实现。每张卡都须完成所有步骤，不能用最后一个集成测试替代前置反例。
