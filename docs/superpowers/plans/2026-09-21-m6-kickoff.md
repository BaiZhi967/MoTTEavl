# M6 开工与交接：实验、比较、统计与门禁

> 状态：planned。本文只定义 M6 的当前开工条件、事实核对和实施顺序，不代表 M6 已实现或已验收。权威工作包细节见 [M6 执行计划](2026-09-21-m6-execution.md)，可整体交给开发 Agent 的提示词见 [M6 development agent](../../prompts/M6-development-agent.md)。

## 1. 目标与完成定义

M6 要把已持久化的 Run、Trial、Observation、ScoreSet 和 ScoringPass 组织成可复核的 Experiment，并通过固定的 ComparisonPolicy、BaselineSnapshot、统计政策和 GatePolicy 产出可供 API、CLI、Web 和 CI 消费的机器结论。

完整 M6 不是“有一个比较函数”或“Run completed”。必须同时满足：

- ExperimentSpec、ExperimentCell、RunReportRef、BaselineSnapshot、GatePolicyVersion、GateResult 均有不可变身份和版本；
- Experiment 只编排现有 Run/Dispatcher/Worker，不创建第二套执行队列、评分器或 current 指针；
- compare/report/gate/历史读取/导出均只读，重复读取零模型、零 Judge、零业务工具调用；
- 失败、unknown、not_attempted、needs_review、不可比和安全阻断不被过滤或补零；
- Direct LLM、GSM8K、C-Eval、Harbor Trial、Scenario/Skill/Judge 都按各自合法分母与证据政策处理；
- API、CLI、Web 和 CI 对同一固定报告返回同一结构化决定；
- 每个目标、工作包和验收场景都有真实消费者、行为测试和持久证据。

M6-Lite（比较条件、覆盖、Baseline、基础 Gate）已有部分代码。开工不复制已有实现，而是先完成公共入口、历史引用和旧库升级核对，再扩展 M6-Full。

## 5. 共享工程规则

- 主 Agent 应主动使用子 Agent 分担边界清楚的纯函数、storage tests、CLI、Web、fixture、文档核对和独立 review，避免主上下文过长；共享契约、migration、storage、API/Worker 和生成文件只能有一个写入负责人。子 Agent 结果必须由主 Agent 审查 diff 并独立复验。
- 每个包先写可收集的行为反例，确认红灯是业务断言失败；ImportError、缺文件、pytest collection error、skip 不算 TDD red，也不算 passed。
- 所有 Experiment/Cell/Run/Case/Trial/Attempt/ScoreSet/ScoringPass/Report/Baseline/Gate 身份分开，固定报告不得读取 current 追随漂移。
- 比较和门禁只消费冻结证据；不在报告读取时重跑模型、Judge、业务工具或改变分数。已 dispatch 但结果未知不自动重放，显式 retry 用新 Run/Cell 身份。
- `unknown`、`partial`、`insufficient_evidence`、`not_attempted`、`indeterminate` 保持原语义；`null` 成本不是 0，未知货币不跨币种相加。
- API 202 只代表持久接收；Experiment 的真实 Run 必须经过现有 Dispatcher/Worker/CaseAttempt/ScoringPass。能力开关只有真实消费者接通后才能打开。
- 不调用付费模型、个人订阅、真实业务工具或生产数据库。live 先形成模型/样本/重复/预算/期限/凭据引用/清理范围的验收包并获得明确授权。
- UI 变更先读 `DESIGN.md`，使用 token、`STATUS_META`、Radix 和 Phosphor；API 变更生成并审查 OpenAPI 与 TypeScript。
- 全部功能完成后必须生成 M6 专项测试集和 A01-A20 对应测试，覆盖 Web、CLI、API、Worker、三种 storage 和跨 suite 集成；可以创建 `m6-accept-*` 合成数据。
- 允许从独立 M6 worktree 启动 API/Worker/Web，并通过真实浏览器和 CLI 走完整公共链路；测试失败必须复现、修复、重跑并更新 `docs/verification/M6.md` 与 `docs/PROGRESS.md`。
