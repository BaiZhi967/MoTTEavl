## 0. 为什么不是「在现有界面上修一修」

你要的是换一套世界。现有界面不是「风格旧」，是**没有系统**：JSX 里用了 `page-title` / `field` / `field-row` / `banner` / `empty-state` / `table` 六个类名，
`index.css` 里**一条规则都没有**；控件样式靠祖先选择器（`form input` / `.operate-card input`）而不是语义类，
所以任何长在裸 `.panel` 里的输入框都会掉回浏览器默认样式。这不是审美问题，是结构问题——修不好，只能换。

## 2. 新世界：信息板（Board）

### 2.1 为什么是它

产品机制是**把一句"行不行"变成可追溯的测量**。而"信息板"这个世界的全部本事，就是**让一排并行单元的状态在一瞥之内成立**：
翻牌牌（Solari）、机场导向、时刻表排版。它天生解决你日常最痛的三件事——多 Run 并行、一眼看谁挂了、从板面下钻到证据。
它不是后台模板，也不是"深色 AI 终端"那套陈词滥调（那是这个品类的可预期反面，刻意排除）。

### 2.2 世界的语法（逐条落到产品）

| 世界规则 | 落到产品 |
|---|---|
| 板面是被**一瞥读完**的表面 | 每个列表页都是"板"：固定列栅格 + 表头带 + 状态列永远在同一列位 |
| 列宽由**重要度**分配，不由内容长度决定 | 列宽固定（Tailwind 主题里的 `--col-*`），标识列拿足预算，**永不截断到不可区分** |
| 数字是材质 | 时间/进度/计数一律 tabular 等宽，右对齐；变化是"翻牌" |
| 状态词表是**封闭**的 | 排队 / 运行中 / 已完成 / 失败 / 已取消 / 未知 —— 不允许自由文本状态 |
| 板有**承诺过的底色**（不是灰上加灰） | 深色信息板作为唯一主题：板体 `#131A22`、表头带 `#1B242E`、墙面 `#0B0F14` |
| 导向系统：你在哪 / 你能去哪 | 顶部信息带（路径 + 板选择器）+ 左侧目录（可收成 56px 图标栏，把宽度让给板面） |

### 2.3 被它击败的挑战者与取舍（掷骰同时发牌的）

| 挑战者 | 判决 | 我从它那里保留的一条纪律 |
|---|---|---|
| 绿磷光终端（午夜机房） | **competitive**（受众认同赢，产品清晰度输：单色等宽会吃掉五语气状态系统，且撞上品类陈词） | **RAISE · 单栏全宽转录**：日志/事件不再装在卡片里，改成一条连续、可搜索、键盘优先的转录面，层级靠缩进与整宽横线 |
| 球鞋档案墙（端面标签） | **competitive**（产品清晰度赢：标签栅格 + 就地抽出） | **RAISE · 端面标签栅格 + 就地展开**：每个单元的标识是固定铭牌栅格；下钻是"把这一行抽出来"，不是跳走 |
| 法式流行唱片封套 | declined | **RAISE · 单一承诺底**：板面表头带是一个承诺过的深底，不是中性灰 |
| 角色周边目录 | declined | **RAISE · 固定铭牌**：每个单元都带同一组固定属性、同一顺序（数据集 revision / scenario 版本 / scoring pass），不是自由字段堆 |
| 重力雨庭 | declined | **RAISE · 可复现的板面查询**：排序/筛选/分组写进 URL，可被结果页与对比页引用（这正是 Replay 的产品承诺） |
| ASCII 现场渲染 | declined | **RAISE · 密度即读数**：逐题信号格用墨量（不是五种颜色）表达通过/失败，把五语气留给状态列 |

### 2.4 方向契约（六个块，实施时按它验收）

- **THESIS**：一屏之内让并行的 Run 状态成立，并让任一读数一步走到它的证据。拒绝的品类默认：侧栏 + KPI 卡 + 状态 pill 表格。
- **OWN-WORLD**：深色搪瓷信息板。方角（2/4px）、2px 表头带分隔、DIN 系窄体大写标签、tabular 等宽数字、状态是"翻牌格"（左侧 2px 语气条 + 封闭词表），不是圆 pill。
- **STORY**：落板面 → 扫状态列 → 打开一个单元的闸口页 → 下钻到题 → 读证据。每一层一次点击，没有死胡同。
- **FIRST VIEWPORT**：运行总览 = 整幅板面。表头带（列名，窄体大写 + 等宽数字）；行高 40px；状态格固定列位；时间右对齐；左上角是路径 + 板选择器；右上角是会话心跳（进行中 N）。
- **FORM**：交通信息板与导向系统，我的候选列表第 5 项（种子 key `4d7aa891`）。
- **FINISH**：未审阅、未登记即为未完工；本轮以验收线（§13）与 DESIGN.md 重建结束。

## 3. 材质与主题（Semi 2.103 + Tailwind 4.3）

### 3.1 主题化策略（第 0 步先做探针，别猜）

Semi 的主题化有两条路，实施前必须用一个探针页确认所选版本实际支持的开关：

1. **编译期**：`@douyinfe/semi-theme-default@2.103.0` 复制为本地主题包，改 SCSS 变量后用 Semi 的主题构建产出 CSS；
2. **运行期**：若该版本编译时打开 CSS 变量模式，则可在 `:root` 覆盖 `--semi-color-*` 等变量。

探针页只放 Input / Select / Button / Table / Tabs，验证四件事：控件默认样式被覆盖、深色底对比度、方角生效、字体重设生效。
**探针不通过就不进入第 1 步。**

### 3.2 颜色（深色信息板，唯一主题）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--board-void` | `#0B0F14` | 页面墙底（工作台背景） |
| `--board-panel` | `#131A22` | 板面 / 面板底 |
| `--board-band` | `#1B242E` | 表头带 / 左侧目录 / 顶部信息带 |
| `--board-cell` | `#101820` | 翻牌格 / 输入控件底 |
| `--board-rule` | `#2A3641` | 一切 1px 分隔线 |
| `--board-rule-strong` | `#3C4B59` | 控件边框 / hover 提亮 |
| `--ink-primary` | `#F2F5F7` | 正文与读数 |
| `--ink-secondary` | `#A9B6C2` | 标签、说明 |
| `--ink-faint` | `#6F7E8C` | 占位、次级时间戳 |
| `--ink-inverse` | `#0B0F14` | 亮底上的字 |

五语气（深色底重调，语义不变，仍是唯一信号系统）：

| 语气 | 深色底值 | 用于 |
|---|---|---|
| info（进行中 / live） | `#57B6D9` | 运行中、链接、焦点、心跳 |
| success | `#4CC38A` | 完成、通过 |
| warning | `#E3A63C` | 需人工处理、证据不足 |
| error | `#E8695F` | 失败、阻断、破坏性 |
| neutral | `#7E8C9A` | 排队、取消、未知 |

语气三件套在深色底上改为：`--tone-*-bg` = 该色 12% 叠在 `--board-cell` 上，`--tone-*-rule` = 该色 100%（用作 2px 左侧条），`--tone-*-fg` = 该色提亮 8%。
**深色底上必须复核对比度：正文 ≥4.5:1，读数 ≥7:1（哈希、JSON、日志）。**

### 3.3 字体与数字

| 令牌 | 值 | 用途 |
|---|---|---|
| `--font-board` | `"Barlow Semi Condensed"` + 中文系统栈 | 表头带列名、板选择器、分节标签（DIN 血统，交通导向的母语） |
| `--font-data` | `"JetBrains Mono"`（仓库已自托管 400/500/600/700） | ID、哈希、时间、时长、进度、JSON、日志 |
| `--font-sans` | 中文系统栈（PingFang SC / Microsoft YaHei） | 正文、说明、表单标签 |

- Barlow Semi Condensed 需自托管 woff2（Google Fonts 许可），`font-display: swap`；
- 中文禁止斜体；中文不参与窄体化（窄体只用于拉丁列名与数字）；
- 全局 `font-variant-numeric: tabular-nums`，数字列一律右对齐；
- 字阶：40 板面大读数（data 600）/ 20 页面标题（sans 600）/ 15 面板标题 / 13 正文 / 12.5 数据 / 11 列名（board，字距 .08em，大写）/ 10 次级标签。

### 3.4 密度、间距、圆角、边框

- **密度两档**（单人专家的真实需求，写进 `localStorage`）：`comfortable` 行高 40px / `compact` 行高 32px，用 Tailwind 主题变量 `--row-h` 驱动，全站一处切换；
- 间距刻度 4 / 8 / 12 / 16 / 24 / 32；板面内边距 16/20；
- **圆角：2px（翻牌格、输入）/ 4px（面板、按钮）/ 0（表头带、左侧目录）**。这是与旧世界最明显的切割：全站不再有 9999px 的 pill；
- 边框：1px `--board-rule`；表头带下方 2px `--board-rule-strong`（导向牌的横线重量）；控件用 `--board-rule-strong`；
- 焦点环：`0 0 0 2px var(--board-panel), 0 0 0 4px var(--tone-info-fg)`；
- 浏览器表面：`::selection` 用 info 12% 叠板底；滚动条 10px、滑块 `--board-rule-strong`、轨道透明。

### 3.5 动效（只有一个是签名动效）

| 场景 | 参数 |
|---|---|
| **翻牌（状态变化）** | 状态格字符两段纵向交换 + 2px 语气条落位，240ms `cubic-bezier(.2,.8,.2,1)`；**只在状态真变化时触发**，不用于入场 |
| hover / 过渡 | 120ms ease，只动背景色 / 边框色 / opacity |
| 行就地展开 | 高度 + opacity，200ms |
| 会话心跳 LED | 1.5s 呼吸（仅进行中） |

`prefers-reduced-motion: reduce` 下：翻牌改为直接替换、LED 恒亮、过渡归零。

## 4. 骨架与导航（导向系统）

```
┌──────────┬──────────────────────────────────────────────────────────────┐
│ 顶部信息带 48：路径 · 板选择器 · 右：会话心跳（进行中 N + LED）        │
├──────────┼──────────────────────────────────────────────────────────────┤
│ 目录 216 │ 板面 / 闸口页 / 签发台 / 转录页 / 对照页                       │
│ (可收 56)│ 工作台是唯一滚动区；滚动下沉进板面内部                          │
└──────────┴──────────────────────────────────────────────────────────────┘
```

- **板选择器**（修你的第 1 条）：套件的五段不再是"灰底上的小白块"，而是导向牌上的**分区选择器**——
  高 32px、`--font-board` 大写标签、激活项是**填充翻牌格 + 2px 底线（info 色）**，非激活项只有底线位。
  权重靠"填充 + 底线 + 字重"三件事拿回来，不靠加阴影；
- 路径（面包屑）改为单行等宽小字，只显示分区与套件，**不再复述页面标题**（页面标题由板面自己的表头承担）；
- 目录：四个分区（总览 / 评测套件 / 资源 / 实验体系），可折叠，导航区内部滚动，底部状态条（API 认证）吸底；
- 收成 56px 图标栏时，板面获得 160px 额外宽度——这是宽表最需要的资源。

## 7. 数据呈现规范（一次性修掉 ③ 与"ISO 原样输出"）

| 类型 | 规则 |
|---|---|
| 绝对时间 | `MM-DD HH:mm`（同年）/ `YYYY-MM-DD HH:mm`（跨年）；一个函数全站唯一；**禁止 ISO 原样输出** |
| 时长 | `25s` / `1m22s` / `2h05m`；未结束显示"进行中 12m"，不是空白 |
| ID | 等宽 + **列宽按最长形态给足，不截断**；确需缩略时保留尾部 4 位 + 点击复制 + `title` 全量 |

## 11. 风险与未决（必须你知情）

1. **Semi 的默认视觉很强**：主题化不足就会变成"又一个 Semi 后台"。三个自研件（`StatusFlap` / `IdentityPlate` / `Board`）+ 方角 + DIN 窄体 + 深色单主题是把世界钉住的手段，缺一不可。
2. **测试成本（最大风险）**：现有 292 条测试大量依赖类名与 DOM 结构，全量替换会大面积打断选择器。第 0 步必须先定策略：把断言从类名迁到 `role` / `label` / `testid`，否则第 5 步会变成"改测试"而不是"改界面"。
3. **深色单主题与证据可读性**：哈希、JSON、日志在深色底上必须实测 ≥7:1，不能靠感觉。
4. **包体积**：当前 bundle 858KB（gzip 238KB）。Semi 全量约 +1MB（gzip 约 +300KB），必须按需引入 + 代码分割，并设体积预算。
5. **迁移期两套世界并存**：`legacy.css` 隔离是硬要求，否则旧规则会污染新页面（这正是当前"幽灵类名"的成因）。
6. **未决**：是否需要保留亮色主题？（本方案是深色单主题；若你白天在强光下用，需要另做一版亮色 token，工作量 +1 步）
